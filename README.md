# TP N°1 - Gestión y Mantenimiento Electromecánico (UTN FRSR)

**Línea Principal de Elevación y Transporte de Áridos de Alta Densidad**

Aplicación interactiva en Streamlit para el análisis de confiabilidad y mantenimiento:

- Taxonomía ISO 14224 (5 niveles) + fichas técnicas.
- Registro de fallas F1-F5 y KPIs (MTBF, MTTR, Ai, Ao).
- Matriz de criticidad dinámica (C = F × Ci) con estimación de frecuencias por repetición de tareas.
- Dashboard de Pareto, tiempos de reparación y estructura de costos (Plotly).
- Exportación del informe profesional a Excel (4 hojas).

## Uso local

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Acceso web

App desplegada en Streamlit Community Cloud (URL pública en el panel de share.streamlit.io).
